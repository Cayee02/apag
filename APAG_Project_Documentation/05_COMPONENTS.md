# Componentes

## Header

Estados:
- transparente sobre hero;
- sólido al hacer scroll;
- menú desktop;
- menú mobile;
- CTA de contacto.

Comportamiento:
- transición suave;
- logo variante clara/oscura;
- accesible con teclado.

## Mobile Menu

Fullscreen.

Debe incluir:
- Inicio;
- Servicios;
- Sobre Nosotros;
- Contacto;
- datos de contacto;
- redes sociales si están disponibles.

Animación:
- overlay;
- links en stagger;
- cierre por ESC;
- bloqueo de scroll;
- focus management.

## Hero

Elementos:
- eyebrow;
- título;
- descripción;
- CTA primario;
- CTA secundario;
- media;
- indicador de scroll.

## Section Heading

Props conceptuales:
- eyebrow;
- title;
- description;
- alignment;
- theme.

## Service Card

Campos:
- número;
- título;
- resumen;
- imagen opcional;
- link/CTA.

## Pillar Card

Campos:
- icono o número;
- título;
- descripción;
- imagen opcional.

## Impact Counter

Solo mostrar cuando existan cifras verificadas.

Campos:
- número;
- sufijo;
- etiqueta.

## Image Reveal

Componente visual reutilizable para fotografías.

## Horizontal Gallery

Desktop:
- pinning;
- scroll horizontal.

Mobile:
- lista vertical o slider táctil.

## CTA Banner

Mensaje institucional + botón.

## Contact Block

## Footer

Bloques:
- marca;
- navegación;
- contacto;

## Floating WhatsApp

No usar burbuja invasiva.

Debe integrarse visualmente a la marca.

## Preloader

Solo primera visita y solo si realmente aporta valor.

Máximo aproximado:
- 1 a 1.5 segundos.

## Custom Cursor

Solo:
- desktop;
- `pointer: fine`.

Nunca en touch devices.
